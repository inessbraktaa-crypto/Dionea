Why Dionea

Built differently, for a reason.

Every design decision serves one goal: catch phishing without slowing your team down.

Automatic

Reads the emails you don't have time to read.

Dionea inspects every suspicious message automatically — headers, SPF/DKIM results, embedded links, sender IPs — and gives you a clear verdict in seconds.

⚡
Transparent

Shows you exactly why an email is flagged.

No black box. Each detection comes with a plain‑English explanation: which check failed, which link looks suspicious, which IP has a bad reputation.

🔍
Deployable

Install in minutes. Open source, always.

Pull it from GitHub, run it on your own infrastructure, and adapt it to your needs. No vendor lock‑in, no hidden fees, no surprises.

🚀
Under the hood

Six layers of automated analysis.

Every suspicious email is inspected across multiple layers — no manual expertise needed.

  • ✓ Email headers & metadata
  • ✓ SPF / DKIM authentication results
  • ✓ Suspicious links and URL reputation
  • ✓ Sender IP addresses & domain reputation
  • ✓ Anomalies in message structure and routing
  • ✓ Full automatic analysis pipeline
